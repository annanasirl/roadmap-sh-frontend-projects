# Roadmap.sh Frontend Projects

My solutions to the frontend projects from [roadmap.sh](https://roadmap.sh/frontend).

This repository contains the projects I develop while working through the **Frontend Developer Roadmap** and its practice projects.

## Projects

### Quiz App

The `quiz/` folder contains my solution to the **Quiz App** project from roadmap.sh.

The project is a browser-based multiple-choice quiz about **Tuscany**, developed in Italian using **React** and **Vite**.

* **Challenge:** [Quiz App](https://roadmap.sh/projects/quiz-app)
* **Folder:** `quiz/`
* **Technologies:** React, JavaScript, Vite, CSS
* **Language:** Italian

More frontend projects will be added to this repository as I progress through the roadmap.
